# Digital Self Studio verification map

Use a fresh dashboard from the [verify skill](../SKILL.md) for each journey. Check `doctor.json` and use the URL and scratch directory printed by that run.

Start with the empty interview, empty memory index, unrecorded prompts, and example persona. Seed each journey through the dashboard controls described in its recipe. Use synthetic answers, chat exports, and recordings in evidence. Record the attempted entry point and unmet precondition when a journey cannot run.

| Dashboard tab | Journeys |
| --- | --- |
| [Conversation](conversation.md) | Send text with the button and Enter, record a voice turn, play the response |
| [Life Interview](life-interview.md) | Select and advance questions, save an answer, reopen it |
| [Voice Studio](voice-studio.md) | Record a reading prompt, replay normalized and master audio, re-record |
| [Memories & Chats](memories-and-chats.md) | Browse, import, search with the button and Enter, clear the query |
| [Persona Matrix](persona-matrix.md) | Edit and save the persona, reopen it, see the name in Conversation |
